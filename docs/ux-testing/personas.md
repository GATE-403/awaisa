# Персоны Awaisa

Четыре человека, для которых мы проверяем сайт. Автоматические проверки берут их из
[`tests/ux/personas.ts`](../../tests/ux/personas.ts): там устройства, условия и бюджеты.
Живые сессии ([moderator-script.md](moderator-script.md)) идут по тем же задачам.

Задачи привязаны к реальным путям по сайту. У каждой есть критерий успеха: что должно
случиться, чтобы задача считалась выполненной без помощи модератора.

---

## 1. Галина Петровна, 68 — старшее поколение, слабое зрение

| | |
|---|---|
| Устройство | Android-телефон дочери (Samsung A-серии), в настройках «Крупный шрифт» (150%). Дома старый ноутбук 1366×768, в браузере масштаб 200% |
| Цифровые навыки | Низкие: WhatsApp, звонки, YouTube. Онлайн ничего не бронировала, к парикмахеру записывается звонком |
| Ограничения | **Зрение:** очки для чтения, начинается катаракта, мелкий серый текст сливается, плохо различает красный и зелёный. **Моторика:** лёгкий тремор, промахивается по маленьким кнопкам. **Терпение:** есть, но боится «нажать не то» и что-то сломать. **Сеть:** домашний Wi-Fi |
| Мотивация | Записаться к «своему» мастеру на окрашивание, не дозваниваясь в салон. Хочет понимать, сколько стоит и что делать, если планы изменятся |
| Что её останавливает | Сообщения, которые исчезают раньше, чем она дочитала. Иконки без подписей. Мелкие серые цены. Ошибка в форме без объяснения |

**Задачи**

1. **Найти услугу.** «Найдите, где можно покрасить волосы недалеко от вас».
   *Успех:* открыта карточка услуги окрашивания или место с ней; цена прочитана вслух правильно.
2. **Записаться.** «Запишитесь в Awaisa Studio на женскую стрижку на ближайший удобный день».
   *Успех:* экран «Вы записаны», она может сказать день, время и адрес.
3. **Войти по SMS.** «Войдите в свой профиль по номеру телефона».
   *Успех:* открыт профиль; ошибка в номере или коде (если была) понята с первого раза.
4. **Отменить запись.** «Вы заболели — отмените запись».
   *Успех:* запись отменена. Если отменила по ошибке, вернула её через «Вернуть».
5. **Оставить отзыв** по ссылке из SMS. *Успех:* поставлена оценка и отзыв отправлен.

## 2. Сергей, 46 — средний возраст, ноутбук и планшет

| | |
|---|---|
| Устройство | Рабочий ноутбук 1366×768 (Windows, Chrome), дома монитор 1920×1080 и iPad |
| Цифровые навыки | Средние и выше: интернет-банк, такси, доставка. Работает в Excel и почте, мышью и клавиатурой |
| Ограничения | **Зрение:** дальнозоркость, на ноутбуке без очков. **Терпение:** мало времени, записывается между совещаниями. **Доверие:** не оставит телефон, пока не увидит цену, длительность, адрес и условия отмены |
| Мотивация | Подстричься и подровнять бороду в обеденный перерыв недалеко от офиса. Сравнивает 2–3 места по цене и отзывам |
| Что его останавливает | Цена, которая появляется только после ввода телефона. Непонятная предоплата. Нет адреса и часов работы на виду |

**Задачи**

1. **Сравнить места.** «Найдите барбершоп со стрижкой до 1 000 сом и хорошими отзывами».
   *Успех:* называет два места с ценой и рейтингом, открывает одно.
2. **Понять условия.** «На странице места найдите цену, адрес и часы работы».
   *Успех:* всё найдено за минуту, без звонка.
3. **Записаться с предоплатой.** «Запишитесь на услугу с предоплатой и оплатите».
   *Успех:* до ввода телефона он знает сумму предоплаты и правило возврата; оплата на тестовой кассе прошла, запись в профиле «Предоплата внесена».
4. **Перенести запись.** «Совещание сдвинулось — перенесите запись на другое время».
   *Успех:* в профиле новое время, подтверждение прочитано.

## 3. Айпери, 21 — молодая, только телефон

| | |
|---|---|
| Устройство | iPhone SE (маленький экран) или iPhone 14. Мобильный интернет, в маршрутке часто «Slow 4G» |
| Цифровые навыки | Высокие: Instagram, TikTok, 2ГИС, оплата по QR. Ждёт, что всё работает как в привычных приложениях |
| Ограничения | **Моторика:** телефон в одной руке, на ходу, большой палец. **Терпение:** бросает, если грузится дольше 3–5 секунд или нужно много печатать. **Сеть:** медленная и рвётся |
| Мотивация | Записаться на маникюр к мастеру из Instagram, желательно сегодня или завтра. Хочет, чтобы о свободном окне ей написали |
| Что её останавливает | Долгая загрузка, лишние поля, мелкие цели под пальцем, нижняя панель, которая закрывает кнопку |

**Задачи**

1. **Найти и записаться быстро.** «Запишитесь на маникюр на ближайшее время».
   *Успех:* «Вы записаны» не больше чем за 6 касаний; не пришлось вводить лишнего.
2. **Войти.** «Войдите по номеру телефона». *Успех:* профиль открыт, код из SMS подставился или введён с первого раза.
3. **Встать в лист ожидания.** «На нужный день всё занято — сделайте так, чтобы вам сообщили, когда освободится».
   *Успех:* видит «Сообщим, если освободится».
4. **Показать талон.** «Покажите запись на входе в салон». *Успех:* талон открыт на весь экран.

## 4. Нурлан, 39 — владелец барбершопа

| | |
|---|---|
| Устройство | Android (Pixel-класс) вечером дома, ноутбук 1366×768 на ресепшене |
| Цифровые навыки | Средние: Instagram-аккаунт салона, WhatsApp Business. Сейчас ведёт запись в тетради и в YCLIENTS-подобной таблице |
| Ограничения | **Время:** заводит страницу урывками, между клиентами. **Терпение:** бросит, если настройка сразу требует много полей. **Сеть:** нормальная |
| Мотивация | Чтобы клиенты записывались сами и не звонили во время стрижки. Видеть день по мастерам |
| Что его останавливает | Длинная анкета до первого результата, непонятные термины, страх «опубликовать не то» |

**Задачи**

1. **Завести страницу.** «Создайте страницу своего барбершопа». *Успех:* открыт кабинет; страница создана за 3 шага.
2. **Добавить мастера.** *Успех:* мастер сохранён, в чек-листе запуска отмечен.
3. **Посмотреть расписание на сегодня.** *Успех:* открыт день по мастерам, он может сказать, кто свободен в 15:00.

### Как добавить новую группу

Добавьте запись в `personas` в [`tests/ux/personas.ts`](../../tests/ux/personas.ts): устройства,
сценарии (`flows`), проверки (`checks`) и бюджеты. Тесты копировать не нужно: проекты Playwright
строятся из этого списка, а тесты отбираются по тегу `@<id персоны>`. Опишите персону здесь же.
