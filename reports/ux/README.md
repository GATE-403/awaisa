# UX-отчёт

Сюда `pnpm test:ux` (или `pnpm test:a11y`) пишет отчёт:

- `index.html` — таблица «персона × сценарий × статус», нарушения по приоритету
  (критично / серьёзно / умеренно) со скриншотами проблемных мест и ссылками на файлы и
  компоненты, затем каждый прогон по шагам, со снимками в симуляциях зрения;
- `results.json` — те же данные для своих выборок;
- `shots/` — скриншоты.

Файлы создаются при каждом прогоне и в git не попадают. Пересобрать HTML из последних
результатов и открыть:

```bash
pnpm test:ux:report
```

Как запускать и что проверяется — [docs/ux-testing/README.md](../../docs/ux-testing/README.md).
